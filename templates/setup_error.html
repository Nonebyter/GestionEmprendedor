Falta configurar Firestore

La app se conecta a Firebase pero la base de datos aun no responde.

  1. Entra a Firestore del proyecto {{ project_id }} y crea la base de datos (modo produccion o prueba).
  2. En la pestana Reglas permite lectura y escritura mientras pruebas: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} { allow read, write: if true; }
  }
}
  3. Recarga esta pagina.

Alternativa mas segura: descarga un serviceAccountKey.json desde Configuracion del proyecto → Cuentas de servicio, guardalo en la raiz del proyecto e instala firebase-admin.
